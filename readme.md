## 🚀 快速开始

项目提供了两个辅助脚本，用于自动创建题目目录与 Git 提交。

### 开始一道新题

```bash
./start_leet.sh
```

脚本会自动检测当前进度（缺失天数会提示中断），然后引导你输入题号与题目名，自动创建：

```
day<天数>_T<题号>/
└── main.cpp      # 预置 Hello World 模板
```

并生成 `.info` 文件记录开始时间与题目信息。

### 结束当前题目并提交

```bash
./end_leet.sh
```

脚本会读取最新目录的 `.info` 文件，统计解题用时，并以 `day<天数>_T<题号>_<题目名>` 为提交信息自动提交到本地 Git 仓库，最后删除 `.info` 临时文件。

> 💡 提示：提交完成后记得 `git push` 同步到远程仓库。
